# Netflix Data Analysis

This is data analysis project based on the Netflix Movies and TV Shows dataset.

The project was created to practice working with real data using Python.
## Project Goals

In this project, I wanted to:

- load and inspect a real dataset
- clean missing values
- convert date columns into a proper format
- compare Movies and TV Shows
- find the top countries by number of titles
- analyze how many titles were added each year
- explore the most common genres
- check the rating distribution
- write key insights based on the analysis

## Tools and Libraries

This project uses:

- Python
- pandas
- matplotlib
- seaborn
- Jupyter Notebook

## Dataset

The dataset used in this project is:

```text
data/netflix_titles.csv
```

## Requirements

The `requirements.txt` file contains the needed Python libraries for this project.

Install them with:

```bash
pip install -r requirements.txt
```

Start Jupyter Notebook:

